# OTF template-matched redesign

This version preserves the supplied Prixa template's core layout, class system, editorial typography, asymmetric hero, project grid, service rows, dark ecosystem section, about layout, principles list, image strip, and CTA/footer composition.

Changes include OTF branding and logo, the analyzed OTF color theme, OTF content/IA, custom CSS-built pixel and network visuals, subtle scroll parallax, original template reveal-on-scroll motion, responsive navigation, and a floating accessibility panel.

## Run
Open `index.html` in a modern browser. No build step is required.
