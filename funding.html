NEED A HAND / 04

Questions before
you get started?

Are all funding programs open year-round?

Not necessarily. Availability and deadlines can vary. Check the official program page for current status before applying.

How do I know which fund is right for my project?

Start with the program descriptions above, then review each fund’s eligibility criteria and supported activities on the official OTF website.

Where can I find the application requirements?

Use the relevant official fund page and the OTF Application Guidebook for current instructions and required materials.

Where can I ask a general question?

Contact OTF at hello@opentech.fund. For program-specific questions, check the relevant fund page first.
